## Featured Project

### InvoiceIQ — AI-Powered Invoice & Expense Automation Platform

A production-oriented, multi-tenant invoice automation platform built with **Java 21, Spring Boot, PostgreSQL, FastAPI, OCR, JobRunr, JWT/RBAC, Docker, AWS S3, and Railway**.

- Multi-tenant architecture with tenant isolation and role-based access control
- Invoice CRUD, validation, idempotency, duplicate detection, and optimistic locking
- Asynchronous document processing with JobRunr and a private FastAPI OCR service
- Deterministic invoice extraction with OCR and financial validation
- Approval workflow with concurrency-safe state transitions and audit logging
- Private AWS S3 document storage with production deployment on Railway
